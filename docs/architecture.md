# 아키텍처 설계

## 모노레포 구조

Turborepo 기반 모노레포. 사용자 앱(web)과 관리자 앱(admin)을 분리하고, 공유 타입은 패키지로 관리.

```
soap-studio/
  apps/
    web/        → 사용자 앱 (PWA, 레시피 조회·계산기·재고 소모)
    admin/      → 관리자 앱 (재료·레시피·몰드·구매단위 관리)
  packages/
    types/      → 공유 타입 정의 (@soap-studio/types)
  turbo.json
  package.json
```

---

## 앱별 역할 분리

### apps/web (사용자 앱)
PWA로 설치해 제작 중 태블릿·폰에서 사용.

| 기능 | 설명 |
|------|------|
| 레시피 목록/상세 | 제작 중 레시피 참조용 |
| 제작 계산기 | 레시피 복수 선택 + 배율 → 필요 재료 합산 + 부족량 파악 |
| 구매 완료 처리 | 부족 재료 구매 후 → 재고 증가 |
| 제작 완료 처리 | 레시피 제작 후 → 사용 재료 재고 차감 |
| 재고 현황 | 현재 보유 재료 잔량 조회 |

### apps/admin (관리자 앱)
데이터 세팅용. 자주 들어가지 않음. 간단한 비밀번호 인증으로 접근 제한.

| 기능 | 설명 |
|------|------|
| 재료 CRUD | 재료 마스터 등록·수정·삭제 |
| 재고 직접 수정 | 초기 세팅 또는 수동 보정용 |
| 몰드 CRUD | 몰드 등록·수정·삭제 |
| 레시피 CRUD | 레시피 등록·수정·삭제 |
| 구매 단위 설정 | 재료별 구매 가능 규격 (5ml / 10ml / 20ml 등) |

---

## 인증

- **web**: 인증 없음 (개인 전용 PWA)
- **admin**: 환경변수로 설정한 비밀번호 단순 일치 확인
  - `ADMIN_PASSWORD` 환경변수 비교
  - 세션 쿠키로 로그인 상태 유지
  - 외부 OAuth 불필요

---

## 공유 패키지

### @soap-studio/types
두 앱이 동일한 타입을 참조. 타입 불일치로 인한 버그 방지.

```ts
// apps/web, apps/admin 모두 동일하게 import
import type { Recipe, Ingredient } from '@soap-studio/types';
```

## 에센셜오일 방울 변환

에센셜오일은 ml 단위로 구매하지만 레시피에서 "방울(drop)"로 표기되는 경우가 있음.
재료 마스터에 `dropsPerMl` 필드를 두어 자동 환산 처리.
- 기본값: 20방울 = 1ml
- admin에서 재료별로 조정 가능
